# NppOmniView v1.1.2 正式版发布说明

## 🚀 核心更新内容 (What's New)

### 1. 🖼️ Markdown 工业级图片排版体系与 OmniGallery 全屏画廊灯箱
- **全屏沉浸画廊灯箱 (`OmniGallery`)**：
  - 点击 Markdown 中任意普通图片即刻弹出交互式全屏灯箱查看器；
  - 完整支持**鼠标滚轮缩放**（10% ~ 500% 范围）、**鼠标拖拽平移 (Pan)**、**顶部缩放比例胶囊指示**；
  - 支持 **1:1 原尺寸** 与 **自适应视口尺寸** 一键快速切换；
  - 支持键盘 **`Esc` 一键关闭** 以及 **键盘方向键 (`←` / `→`)** 快速在文档各图片间来回切换；
  - 智能识别包裹超链接的图片，点击优先触发原生链接跳转，杜绝误拦截。
- **本地资源物理路径智能解析与沙箱虚拟代理**：
  - 动态嗅探当前 Notepad++ 正在编辑文件的物理磁盘真实路径，自动将相对路径映射并注入 `baseHref`；
  - 支持本地绝对路径（`file:///`、`C:/...`）的沙箱代理安全规整，彻底解决本地 Markdown 配图加载失败或跨域被阻断的问题。
- **现代图片样式全景重构**：
  - 为图片注入自适应最大宽度限制（`max-width: 100%`）、精致微圆角（`8px`）、柔和边框与悬浮微动效；
  - 原生支持 `<figure>` 与 `<figcaption>` 图题注居中排版；
  - 外部 Web 链接（`http://` / `https://`）自动附加右上角轻量外链指示箭头（`↗`），并严格排除图片包裹外链。

### 2. 💎 Shell / SQL / Python 脚本大纲体验重构与排版抛光
- **消除目录索引 (TOC) 的“两个圈圈”重叠缺陷**：
  - 彻底拔除针对锚点链接滥用的 `::before` 灰色伪圆圈，彻底根除与 HTML 原生列表标记符（`•` / `◦`）重叠导致的“双圈圈”视觉瑕疵；
  - 优化全局列表与目录项层级行高、间距，使其呈现专业技术文档的高质感。
- **大纲卡片系统现代高颜值升级**：
  - 采用全新 `.sql-item-card` 网格系统，具备柔和自适应边框与悬浮上浮微动效（`translateY(-1.5px)`）；
  - 引入不同类型的专属配色徽章体系（函数 `FUNC`、表 `TABLE`、视图 `VIEW`、过程 `PROC`、查询 `QUERY`、分段 `SECTION`、依赖 `SOURCE` 等）；
  - 标题采用等宽代码字体显示，右侧附带精致行号胶囊（`第 X 行 →`），并完整深度适配 Notepad++ 深色模式 (Dark Mode)。
- **实时过滤搜索与精准双向代码行定位**：
  - 支持大纲符号的极速关键字实时搜索过滤；
  - 单击任意大纲卡片即可毫秒级驱动 Notepad++ 编辑区光标精准跳转至目标代码行并聚焦。
- **布局防遮挡优化与冗余面板精简**：
  - 修复固定顶部工具栏导致的卡片顶部截断遮挡缺陷，将容器顶部内边距扩展至 `86px`；
  - 全面移除侧边栏中冗余的只读源码视图与失效的切换按钮，大幅降低内存消耗，专注于纯粹的大纲结构导航。

### 3. 📐 代码块前导缩进自动剥离 (Auto-Dedent) 与阶梯缩进美化
- **公共前导缩进自动消除 (`dedentCode`)**：
  - 自动识别并剥离代码块所有非空行的最长公共前缀空白（支持 2/3/4 空格或制表符等任何统一缩进），终结代码整体靠右偏置的问题；
  - 100% 保持内部相对层级，贴左呈现，复制、行号和高亮均基于去缩进后的规范代码。
- **JSON 片段智能美化与容错解析**：
  - 深度强化片段 JSON 解析与美化算法，完美兼容无顶层 `{}` 包裹的键值对片段，自动剔除外层包裹并消除首层多余缩进；
  - 富代码块默认初次呈现即自动应用标准阶梯层级缩进（2 空格 / 4 空格），从根源终结平齐无缩进代码；
  - 代码块 Header 恢复常驻高质感【美化】按钮，支持随时按需重新排版。

### 4. 🔄 双向滚动同步与视口缩放完善 (汇总 1.1.1 修复)
- **Scintilla 双向滚动监听完整化**：
  - 修复 `SCN_UPDATEUI` 通知中遗漏垂直滚动标志（`SC_UPDATE_V_SCROLL = 0x04`）的核心缺陷，鼠标滚轮、拖拽滑块、按键翻页均可毫秒级实时驱动预览视口平滑同步；
  - 增强 Markdown 锚点末尾插值机制，滚动至文档底部时光标与页面底端自然咬合。
- **HTML 格式 1:1 原尺寸内容截断修复与自由缩放**：
  - 彻底拔除 Flexbox 居中容器的负坐标溢出截断陷阱，滚动条从 `(0, 0)` 开始，页面左侧与顶部 100% 完整可见；
  - 新增放大（`+`）、缩小（`-`）步进微调按钮以及自由显示比例预设下拉菜单（25% ~ 200%），支持 `Ctrl + 滚轮` 平滑缩放。

## 📦 安装与升级指引 (Installation)

### 手动安装 / 升级：
1. 下载下方发布资产中的 `NppOmniView-v1.1.2-x64.zip`；
2. 彻底退出 Notepad++；
3. 将压缩包解压，把里面的 `NppOmniView` 文件夹整体复制到 Notepad++ 安装目录下的 `plugins\` 目录中（例如 `C:\Program Files\Notepad++\plugins\` 或便携版 Notepad++ 的 `plugins\` 目录下）；
4. 确保目录结构为 `plugins\NppOmniView\NppOmniView.dll`；
5. 重新启动 Notepad++，即可在顶部菜单栏 `插件 (P) -> NppOmniView` 或点击工具栏图标开启体验。
